This repository contains ripped files from youare.swf, the swf which was used in Trojan.JS.Offiz (also known as Trojan.JS.Youareanidiot or trojan.spawn/offiz). You can google trojan You are an Idiot, on google there's pretty much info about this trojan, but not every info is full/true. We are making our own wiki and you can check it here: offiz.cc, but it can be down sometimes and on the moment of creation of this repository, this site is W.I.P.
What it contains:
- Shapes (the smiley faces on background)
- Font, which was used in youare.swf. (It's not a full font, the .swf contained unfinished font, which included only letters a, d, e, i, n, o, r, t, u, y. The original font was Times New Roman.
- Original youare.swf, so you can decompile it yourself or just watch it.
- All 56 frames from youare.swf
- The original "You are an Idiot! Hahahaha" sound
- Smiley face sprites, which weren't included in original .swf file. These smiley faces were extracted from the .svg files in shapes, the background was removed and I putted smiley faces by 1. There are two variations: White and Black.
